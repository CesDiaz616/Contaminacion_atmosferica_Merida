# Contaminacion_atmosferica_Merida
Monitoreo ambiental especializado para diagnosticar de manera puntual la presión atmosférica sobre la calidad del aire en el municipio de Mérida, Yucatán. El objetivo central fue correlacionar la cúpula de contaminación urbana con la distribución geográfica de los establecimientos económicos locales. Para lograrlo, se estructuró una metodología híbrida que vincula la teledetección satelital con los censos económicos vectoriales, unificando la información a nivel de Áreas Geoestadísticas Básicas (AGEB) urbanas para facilitar la planeación territorial y la comunicación social de los resultados.
